# ONB-004.4 — Ciclo de vida da sessão

Base PR #97 incorporada, quatro pipelines SUCCESS. Fixture isolada reutiliza AMR assinado e consulta de sessão vigente. Estado de aplicação privado, por sessão, com inatividade 30 min, duração absoluta 8 h, revogação persistente e trava por sujeito compartilhada pelas operações. Testes HTTP e verificação SQL de efeitos; avanço temporal de inatividade/duração por fixture administrativa local, não espera real desses intervalos. Expiração de JWT emitido pelo Auth: configuração 300 s e espera até exp + 65 s. Revogação de aplicação não equivale à revogação do refresh pelo provedor: token renovado deve continuar sem acesso; logout do provedor deve rejeitar refresh. Corrida via Promise.all e conferência de efeitos não garante interleaving determinístico; barreiras e ordem de entrega de leitura, concorrência com logout externo, reavaliação no commit e advisors permanecem pendentes. Nenhuma alegação de atomicidade distribuída. Testes NOT_EXECUTED até CI. Sem SDK/UI, migração de produção ou dados infantis. #27/#29/#35/G5 preservados.
